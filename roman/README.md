# Sahrana bez tela

Rukopis romana i radni dokumenti revizije. Repo postoji iz jednog razloga:
**git pamti svaku verziju teksta**, pa se stara i nova verzija poglavlja mogu
uporediti red po red. Do sada su verzije živele samo na Drive-u i u Claude
projektu, gde se prepisivanje ne vidi.

## Šta je gde

```
roman/
  poglavlja/   osam poglavlja, radne .md verzije
  dokumenti/   pravila, svet i likovi, tok revizije
```
